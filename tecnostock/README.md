# TecnoStock - Sistema de Gestión de Inventario Web MVP

## Requisitos
- PHP 8.0+
- MySQL 5.7+ / MariaDB
- XAMPP / WAMP / MAMP

## Instalación
1. Extraer la carpeta `tecnostock` dentro de `htdocs` (ej: `C:\xampp\htdocs\tecnostock`).
2. Iniciar Apache y MySQL en XAMPP.
3. Importar el script `database/schema.sql` en phpMyAdmin (`http://localhost/phpmyadmin`).
4. Abrir en el navegador: `http://localhost/tecnostock/login.php`.
